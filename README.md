# HelmetRelay

Полудуплексная ретрансляция звука между Bluetooth-гарнитурой шлема и телефоном (Android 12+, проверялось только на уровне кода; на устройстве не тестировалось).

- Режим 1 «Слушать»: микрофон телефона → динамики шлема (через A2DP, если его нет, через SCO).
- Режим 2 «Говорить»: микрофон шлема (SCO) → динамик телефона.
- Одновременно работает только один режим.
- Переключение: кнопки в приложении или кнопки в уведомлении.
- В нижней части экрана выводится журнал: какие устройства найдены и по какому маршруту фактически идёт звук.

## Сборка без Android Studio

1. Залить проект в GitHub-репозиторий (ветка main).
2. Вкладка Actions → Build debug APK → Run workflow (или запустится сам после push).
3. После завершения: открыть запуск → раздел Artifacts → HelmetRelay-debug-apk → скачать zip → распаковать → установить APK на телефон.
4. На телефоне разрешить установку из неизвестных источников.
